# Octypst working notes

- The canonical shared repository is `github.com/gvrooyen/octypst`; this checkout may also have an Amp remote. Check both branches before pushing.
- Use `make check` for both branded sample PDFs and the table alignment regression. `bin/new-report <destination>` creates a standalone copy; compile its `report.typ` as well when changing generation or template paths.
- The live preview is declared in `.amp/services.yaml`. Run `amp orb services ensure` from the repository root (or a generated report folder) and use its printed portal URL. Do not run the watcher as an unsupervised background process. In this repository it defaults to `sample_report.typ`; in a generated folder it defaults to `report.typ`. Set `OCTYPST_PREVIEW_SOURCE` in the service environment or pass `--source` in the service command to switch reports; restart the service after changing its configuration.
- The viewer renders PNG pages and preserves its scroll position on successful rebuilds. **Open PDF** serves the separately compiled, selectable PDF. Inspect representative rendered pages (cover, body, and affected non-default states such as wrapped tables) after visual changes, not just build output. Check `/api/version` and `amp orb service logs pdf-preview` when builds fail; the last good preview should remain visible.
- Generated PDFs and `.amp/preview/` and `.amp/portals/` are ignored. Keep source files and brand assets tracked; don't commit preview output.
